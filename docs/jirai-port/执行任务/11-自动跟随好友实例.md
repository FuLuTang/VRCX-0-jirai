# 11：自动跟随好友实例

## 目标
尽量还原旧 Jirai：选择一个好友后，监听其真实实例 location 变化；变化且与自己的 last location 不同时立即打开/重启进入该实例。此任务按用户要求低验证优先级。

## 依赖与边界
无数据表依赖，可在 03 后并行；不等同于非好友追踪，不处理多个目标，不实现推荐联动。

## 旧代码可复用分析
旧完整逻辑在 `src/stores/autoFollow.js:12-83`：保存 active/target、watch friend location、`isRealInstance` 判断、比较 `lastLocation`、根据 VR 游戏状态调用 launch/quit。该控制流与零延迟策略可复用；Pinia watch、toast 与 `AppApi` 调用必须映射当前 store/service。

## 子代理引导
“仅实现单目标状态机和已有启动服务调用。目标失效/离线/非真实实例不动作；切换实例时防重复 launch。默认关闭，设置/菜单入口最小化。不要碰非好友、数据库、自动邀请。”

## 检查标准
- 选中目标、停止、重新选择正确；
- 相同 location/非真实实例/离线不启动；
- 新真实实例只触发一次 launch；
- 游戏运行/未运行分支调用当前等价服务；
- 以 mock 测试为主，GUI 实机验证由用户后续专项确认。
