## P1：Tauri GUI 主路径手测

先构建运行（`npm run tauri dev` 或项目既有命令）。以下每条都给出「操作 / 预期 / 可疑现象」。

### 05 启动 Online 补线

- **操作**：正常登录，等好友列表加载完成，打开 Feed。
- **预期**：为「当前在线、且历史上没有 Online/Offline 记录、或最后一条是 Offline」的好友补一条 `Online`，时间约为启动时刻。
- **可疑**：最后一条已经是 `Online` 的好友被重复写入；出现任何 `Offline` 补写；好友列表为空/加载失败时也写记录（应无写入）。

### 06 已跟踪非好友

- **侧栏操作**：打开侧栏的 tracked nonfriends 页签 → 输入一个**非好友**的 `usr_xxx` ID → 添加。
- **预期**：列表出现该条目；删除后立即消失；无数据时显示空态；查询失败时显示错误态而不是空白。
- **资料菜单操作**：打开一个**非好友**的用户资料 → 操作菜单里应出现「跟踪该用户」项（`tracked_nonfriends.add_user`），已跟踪时变成移除项。
- **好友对照**：打开一个**好友**资料 → 该菜单项**不应出现**。
- **账户隔离（重点）**：切换账户后，列表**绝不能**短暂显示上一个账户的条目。
- **可疑**：把非好友加进了好友列表/互惠图；菜单项在好友资料上出现；切账号残留旧数据。

### 07 手动关系独立层

- **操作**：Charts → Mutual friends → 工具栏的关系图标按钮 → 打开「手动关系」对话框 → 输入两个 `usr_` ID 添加。
- **预期**：图上出现**绿色**覆盖边，图例里有对应的手动关系项；删除后边消失。
- **关键对照**：添加/删除手动关系**不应改变**已抓取的互惠数据（节点数、观测边计数、快照内容都不变）。
- **可疑**：观测数据被改动；绿色边与观测边无法区分；同一对人 A↔B 和 B↔A 产生两条记录。

### 08 自动资料抓取

- **操作**：Tools → Automation → 同步 workflow 对话框；也可直接等登录后的自动触发。
- **预期**：动作「自动资料抓取」显示**真实状态**（执行中/完成/取消），不再是「跳过」；完成后 Feed 中只在 Bio 真正变化、或状态变化为 `join me` / `active` / `ask me` / `busy` 时才新增记录。
- **非好友纳入**：在 06 里添加一个非好友，再触发一次，该非好友的资料也应被抓取。
- **可疑**：状态没变也写记录；写入 `offline` 等非白名单状态；失败目标阻塞后续目标；取消后仍在发请求。

### 04 同步 workflow 对话框

- **操作**：Tools → Automation → 打开同步 workflow。
- **预期**：动作目录一次显示完整；各动作状态真实（不伪造不可用动作）；能取消正在执行的动作。
- **可疑**：打开时空白；把未实现的动作显示成已完成。

### 02 Feed 图片拖放

- **操作**：把一张图片文件从文件管理器拖到 Feed 页面上，分别对准五个目标区（gallery / icons / emojis / stickers / prints）。
- **预期**：命中目标区后跳到 Gallery，并进入既有的裁剪 → 上传流程。
- **可疑**：拖入后无反应；多张图片被接受（应只处理单张）；命中区域判定偏移。
