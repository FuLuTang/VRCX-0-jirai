## 增强型信息抓取

- 工具 → 系统工具、状态栏及社交设置已接入口，统一名称“增强型信息抓取”。浮窗展示运行概况、分层策略、本轮成功／未变／失败／缺字段和已确认落盘更新数量；关闭浮窗不中止后台任务，显式取消才停止。
- 好友基线完成、重连与周期基线刷新可触发自动抓取；自动增强默认开启，手动全量复用同一服务。目标为好友＋显式追踪非好友，按账号去重与取消。保持 VRCX-0 原有实时事件及群组、收藏维护。
- 用户资料的名字／灯色／状态短语来自 `/users`，公开 Bio 来自 `/profile`，不回退使用旧的 `/users` Bio。缺字段不是清空；明确空 Bio 可记录。原生观察与批量资料共用比较落盘及 Feed 更新通知。
- 强刷只合并正在进行的同账号、同对象、同类请求，不保留五分钟完成结果缓存。串行请求、有界重试；429 暂停队列，保留 HTTP Retry-After，缺等待信息时退避五分钟。运行中的下一次重试可显示；周期触发依赖真正完成的好友基线，不伪造精确倒计时。
- 打开其他玩家资料时，好友与非好友均可保存有效快照。增强自动打开时抑制重复的渐进 Bio 扫描；关闭时保留原有扫描开关与行为。
