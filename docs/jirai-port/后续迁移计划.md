# VRCX-0-jirai 后续功能还原计划

复核日期：2026-10-11。代码基准：VRCX-0 v2.31.0（`620fb2b3a`）已合入当前分支；最新集成提交为 `61130e43b`。本计划与状态以 [功能补全清单](../jirai-feature-backlog.md) 为准，实机验收步骤见 [待手测清单](待手测清单.md)。

## 当前结论

增强型信息抓取、关系建议／进房提醒、灯色占比、双人关系收尾、Bio Diff、关系图 OLD 历史、追踪非好友列表，以及个人资料自身 Bio／Activity 查询接线均已接入。它们仍有真实账号、数据库或 VR 手测项，但不应再次当作“尚未移植”重做。VRCX-0 v2.31.0 的关系通知架构变化已适配：提醒现在经 `ActivityEvent`／`ActivityRouter` 投递；通知过滤和其他 VRCX-0 改动保留。

搜索／搜索框相关功能依用户决定暂缓。多账号需要单独设计游戏日志归属和认证会话，不作为小型迁移任务。VRCX-Luo 的双人世界排行是可选增量；好友侧栏动画暂不排期。

## 本轮收尾：个人资料页自身历史查询

这不是新做一套“完整活动历史”。现已修正两个具体接线差异：自身 Bio／状态从 `self_profile_log` 读取，用户资料窗口 Activity 查询显式按目标用户传 `isSelf`。独立活动热力图保持原样。接下来按待手测清单验收，不扩大本项范围。

### 本轮改动范围（仅修正现有查询）

1. 自身 Bio 历史走当前账号 `self_profile_log`，好友 Bio 历史保持 Feed 查询。
2. 用户资料窗口 Activity 查询按目标用户与当前用户是否相同设置 `isSelf`。
3. 只沿用已有记录和 UI；不新增表、新时间线或“完整历史”，不重做活动热力图。

### 代码参考

- 旧体验：`VRCX-jirai/src/components/dialogs/UserDialog/UserDialogActivityTab.vue`、`VRCX-jirai/src/components/dialogs/UserDialog/UserDialogStatusDistributionTab.vue`。
- 当前 UI 与查询：`VRCX-0-jirai/src/components/dialogs/user-dialog/components/UserDialogInfoTab.tsx::UserDialogBioPanel`、`src/components/dialogs/user-dialog/useUserActivityPanelController.ts`、`src/services/userActivityViewService.ts`、`src/features/activity/useActivityHeatmap.ts`。
- 自身数据写入／读取：`VRCX-0-jirai/crates/application-realtime/src/realtime/current_user/self_profile.rs::append_self_profile_observations`、`crates/persistence/src/realtime/write.rs::observe_self_profile_field`、`crates/persistence/src/realtime/self_status_history.rs`、`crates/persistence/src/activity/view.rs::self_activity_source`。

### 验收边界

- 当前用户的查询只读当前账号；切换账号后不残留上一账号结果，读取失败与无记录空态可区分。
- 自身 Bio、状态和状态短语只显示 `self_profile_log` 实际保存的变化；本轮不扩展上下线明细。
- 好友 Bio Diff 和好友活动查询不受影响；不引入数据库迁移或新的全量 API 扫描。
- 前端测试覆盖自我参数传递、当前账号作用域、空态／失败态及用户切换；Rust 测试覆盖自身历史读取的账号隔离与数据来源边界。最后用实际账号手测。

## 实施前置检查

- 2026-10-12 已完成本轮代码级检查：persistence 477 项测试（1 项忽略）、application／game／activity／desktop-host 测试、Tauri devtools／SteamVR／OpenXR 特性组合 `cargo check`、Specta 绑定生成、前端类型检查和生产构建均通过。
- 桌面开发运行仍有未解决的 Windows `softbuffer 0.4.8` 位图断言崩溃；编译通过不代表窗口运行稳定。按 [待手测清单](待手测清单.md) 继续验收启动稳定性、真实账号／数据库、增强抓取、好友关系归档、关系提醒、两张关系图和数据库迁移；发现的问题单独修复，不与自身历史功能捆绑。

## 当前不做

- 快捷搜索、最近遇见对象和 Bio 搜索：暂缓，等待用户决定如何融合搜索框。
- 多账号同时登录／合并视图：需先解决游戏进程与单一游戏日志源归属。
- 自动跟随、从历史实例伪造同行记录、VRCX-Luo 双人共享世界排行：独立评估，不并入本轮。
- 好友侧栏上线动画：暂不排期，避免增加低收益状态动画复杂度。
